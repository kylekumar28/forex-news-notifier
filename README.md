# TradeFence

TradeFence is a cross-platform economic news notification app designed for traders.

It displays high-impact economic events and allows users to configure notifications before major releases and after a configurable post-news waiting period.

## Features

- High-impact weekly economic calendar
- My Alerts / All News calendar filtering
- Currency-specific alert preferences
- Configurable pre-news notifications
- Configurable post-news buffer notifications
- Local notification scheduling
- Past/upcoming event distinction
- Stale calendar data indication
- Offline calendar cache fallback
- iOS and Android support

## Technology

- React Native
- Expo
- Expo Router
- TypeScript
- Firebase Realtime Database
- Expo Notifications
- AsyncStorage
